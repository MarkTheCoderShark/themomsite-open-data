# The Mom Site open data

State-by-state data on what pregnant people and new parents can get in the US, plus the doula workforce counts behind our 2026 report. It covers all 50 states and DC. Every state record lists the sources it came from.

This is the data behind [themomsite.com](https://themomsite.com/). It is free to reuse under [CC BY 4.0](LICENSE), with credit to The Mom Site.

**DOI:** [10.5281/zenodo.23492658](https://doi.org/10.5281/zenodo.23492658) (Zenodo, all versions). The benefit files are also on [Kaggle](https://www.kaggle.com/datasets/mrktheshrk/us-pregnancy-and-family-benefits-by-state-2026); the doula workforce CSVs have their own record, [10.5281/zenodo.23491731](https://doi.org/10.5281/zenodo.23491731).

### How the JSON files are shaped

Each benefits file follows the same outline:

```json
{
  "topic": "doula-medicaid",
  "title": "Medicaid coverage of doula care by state",
  "asOf": "2026-10",
  "methodology": "How we built it, in plain words",
  "sources": [{ "id": "…", "title": "…", "publisher": "…", "url": "https://…", "accessed": "2026-10-09" }],
  "national": { "factName": { "text": "…", "sourceIds": ["…"] } },
  "states": { "TX": { "status": "not-covered", "summary": "…", "sourceIds": ["…"], "notes": "…" } }
}
```

- `states` always has 51 keys: the 50 states and DC, by USPS code.
- `sourceIds` point to entries in that file's `sources` list. Every figure in a state record comes from those sources.
- `status` values differ by topic. For example, `doula-medicaid.json` uses `covered`, `enacted` (approved, not paying yet), `pending` (rates or rules in progress) and `not-covered`. `paid-family-leave.json` uses `paying`, `enacted`, `voluntary` and `none`.
- `unverified` means we couldn't confirm the rule from an official source. We don't guess. Check with the state agency.
- Some records carry `evidence`: the field it supports, the source URL and a short quote from that source.

### The doula workforce columns

`doula-workforce-2026.csv` has one row per state plus a `US` total row:

| Column | Meaning |
|---|---|
| `state`, `state_name` | USPS code and name |
| `doula_npis` | Active NPIs that list the doula taxonomy code (374J00000X) in any of their 15 taxonomy slots, placed by practice location state |
| `individual_npis`, `organization_npis` | Split by NPI entity type |
| `sole_proprietor_npis` | Individuals who set the NPPES sole proprietor flag (self-employed, not incorporated) |
| `issued_2023_or_later`, `pct_issued_2023_or_later` | NPIs issued from January 1, 2023 on, and their share |
| `births_2024` | Final 2024 births by mother's state of residence (CDC NVSR vol. 75, no. 2, Table 5) |
| `doula_npis_per_1000_births` | `doula_npis / births_2024 × 1,000` |
| `medicaid_doula_status`, `medicaid_doula_effective_date` | From `doula-medicaid.json`, October 2026 |
| `medicaid_list`, `medicaid_list_basis`, `medicaid_list_count`, `medicaid_list_as_of` | The five state doula lists the directory uses. `enrolled` is a Medicaid enrolled-provider directory, `registry` a state registry and `network` a health plan's network list. Counts aren't comparable across states. |

`doula-npis-by-year-2026.csv` has `enumeration_year`, `doula_npis`, `individual_npis`, `organization_npis` and `partial_year`.

**Read the counts as NPIs, not working doulas.** An NPI is free, and a doula needs one to bill Medicaid or private insurance. Doulas paid only by their clients have no reason to get one, so NPPES undercounts doulas. NPIs also don't expire, so some belong to people who no longer practice. More doula NPIs where Medicaid pays doulas is a correlation, not proof that coverage created more doulas. The report lists all eight limits.

## Sources

Each file's `sources` list gives the title, publisher, URL and the date we read it. The main ones:

- **Medicaid for pregnancy:** income limits are KFF and Georgetown University Center for Children and Families survey figures as of January 2026 (KFF State Health Facts). Postpartum coverage comes from KFF's extension tracker and state announcements. Programs and apply links come from state Medicaid agencies, and poverty guidelines from HHS.
- **WIC:** USDA's 2026–2027 income eligibility guidelines (Federal Register, April 29, 2026), plus each state WIC agency.
- **Paid family leave:** each state program's site and the law itself, compared with the National Partnership for Women & Families' April 2026 chart.
- **Doula and lactation coverage, breast pumps:** state Medicaid provider manuals, fee schedules, bulletins, administrative rules and CMS-approved state plan amendments. Private-plan pump rules come from HRSA's Women's Preventive Services Guidelines, 45 CFR 147.130 and the federal ACA FAQs. The doula file started from the National Health Law Program's Doula Medicaid Project and NASHP's March 2026 analysis, then checked every state against its own documents.
- **Child care assistance:** each state's own program pages and published income charts, cross-checked against Childcare.gov (ACF). Where a state publishes no chart, the income limit comes from the National Women's Law Center's 2025 survey (policies as of February 2025). Copay caps come from each state's FFY 2025–2027 CCDF plan.
- **Childcare prices:** the US Department of Labor Women's Bureau National Database of Childcare Prices.
- **Car seat laws:** each state's statute on its official legislature or code site, with highway safety agency pages where the code host couldn't be read. Recommendations come from NHTSA and the AAP.
- **Doula workforce:** the CMS NPPES downloadable file (September 2026 release), the NUCC taxonomy code set, and CDC NCHS final 2024 births.

Two things in these files aren't ours to license:

- **Quoted excerpts.** The `quote` text in `evidence` records is a short excerpt from the cited source, there so you can check our reading. It stays under its owner's terms.
- **Third-party figures.** A few fields carry another organization's published figures, named in the field or its source: KFF/Georgetown CCF income limits, the `kff_2021_*` columns in the breast pump CSV, and the `*_nwlc` columns in the child care assistance CSV. Credit those organizations too when you reuse those figures.

Not included: the WIC clinic lists behind our WIC office pages (some states, including North Carolina and Texas, don't allow commercial reuse of theirs), and the provider directory (built from CMS NPPES, which you can download from CMS directly).

## Rules change

These are rules and prices as of the dates above, not legal, medical or financial advice. Programs change their limits every year. Before you rely on a figure, check it with the agency named in the record.

Found an error? Tell us through the [contact form](https://themomsite.com/contact/) and choose "Report an error in a guide or benefit figure". Our corrections policy is on the [editorial policy page](https://themomsite.com/editorial-policy/#corrections).
